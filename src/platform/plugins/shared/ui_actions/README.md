# UI Actions

Registers **triggers** (user intents such as clicking a value or opening a panel menu) and **actions** that run in response. Plugins attach actions to triggers at runtime so one plugin can extend another plugin's UI.

See the [UI Actions](../../../../../docs/extend/key-concepts/ui/ui-actions.md) key concept, `common/trigger_ids.ts` for built-in trigger IDs, and [`examples/embeddable_examples`](../../../../../examples/embeddable_examples) for a maintained consumer.
