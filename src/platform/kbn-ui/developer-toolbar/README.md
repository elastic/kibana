# @kbn/ui-developer-toolbar

Portable home of Kibana's developer toolbar. The toolbar shell, its built-in monitors and the toolbar tools move here from `@kbn/developer-toolbar`, `@kbn/design-tools` and the `inspect_component` plugin in follow-up commits.

**Portability:** candidate for extraction to Cloud UI. The package has no `@kbn/*` runtime dependencies and builds to a standalone tarball via `packaging/scripts/build.sh`.
