# Developer Toolbar Example

Minimal test application for the `@kbn/ui-developer-toolbar` package.

## Setup

```bash
# From the Kibana root
pnpm kbn bootstrap

# Build the package
cd src/platform/kbn-ui/developer-toolbar/packaging
./scripts/build.sh
```

## Run

```bash
cd src/platform/kbn-ui/developer-toolbar/packaging/example
pnpm start
```

Opens http://localhost:3000.
