# @kbn/chart-icons

Shared icons for Kibana visualizations:

- **SVG assets** for chart types, axes, legends and annotation markers that EUI doesn't provide.
- **`resolveVisIcon`**, a stable resolver for icon identifiers saved in visualizations (annotations, reference lines, metric, Graph). It maps current and legacy identifiers to the icon to render, so saved objects icons still resolve when identifiers change.
