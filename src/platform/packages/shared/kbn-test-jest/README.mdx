# Jest testing

`@kbn/test-jest` owns the Jest CLI, presets, configuration discovery, transforms,
and reporters. Use `@kbn/test-jest` for Jest runner APIs and presets such as
`@kbn/test-jest/jest_node`. FTR APIs remain in `@kbn/test`.
