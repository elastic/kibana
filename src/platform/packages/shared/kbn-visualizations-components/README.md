# @kbn/visualizations-components

Browser-only React components and styles shared by visualization renderers: `VisualizationContainer`, `VisualizationNoResults`, `VisualizationError`, `ChartTooltipFooterMessage`, `visualizeClassName` and `visContainerStyle`.

Types, constants and other server-safe code live in `@kbn/visualizations-common` and `@kbn/chart-expressions-common`.
