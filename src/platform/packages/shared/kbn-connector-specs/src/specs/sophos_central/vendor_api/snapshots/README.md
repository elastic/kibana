# Sophos Central OpenAPI Snapshots

Sophos Central does not publish a publicly downloadable OpenAPI specification file.
The API documentation is available at https://developer.sophos.com and requires
authentication to access the interactive API explorer.

The manifest, overlay and fixtures in this directory were built from the published
documentation at:

- Common API v1: https://developer.sophos.com/docs/common-v1/1/overview
- Endpoint API v1: https://developer.sophos.com/docs/endpoint-v1/1/overview
- Detections API v1: https://developer.sophos.com/docs/detections-v1/1/overview

When Sophos publishes a downloadable OpenAPI spec, place the snapshot here as
`default.openapi.json`.
