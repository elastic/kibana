You are an expert SRE judging the quality of an AI-generated incident RCA report.

You are given two things:
1. The CONFIRMED root cause. It was established AFTER the alert resolved (reconciled
   against what actually mitigated the alert), so it is ground truth. Judge against
   this, not against anything the report merely asserts. It may refute the report's
   cause without naming another one; that refutation is ground truth too.
2. The AI agent's incident RCA report, produced DURING the original investigation
   (before the resolution was known).

Base every answer only on evidence present in the agent's report. If the report does
not state or cite something, treat it as absent (answer false). Do not give credit for
a cause the report does not actually name just because it is the confirmed one.

Answer each boolean, then assign the 0-3 score.

root_cause_match: Did the report identify this confirmed root cause? Credit a
  generalization, specialization, synonym, or paraphrase of the same mechanism; refuse
  only when the report names a genuinely DIFFERENT mechanism. A report may name several
  candidate causes — mark true if the confirmed cause is among them.
mechanism_match: Did the report correctly explain the mechanism --- how the root cause
  propagates to the user-visible / alerting symptom?
evidence_match: Did the report cite concrete supporting signals for this cause
  (specific metrics, logs, traces, timestamps, services, deploys, or config keys) rather
  than asserting the cause without grounding?

## Per-Rubric Scoring Rubric
Assign an integer score from 0 to 3 reflecting how well the report matches the confirmed
root cause:
  0: findings are misaligned with the confirmed mechanism and completely miss this cause
  1: the report confirms the symptoms described by the alert but does not investigate
     further toward this root cause
  2: the report makes correct progress beyond symptoms --- it identifies some of the
     ground-truth signals and moves toward this root cause, but does not fully identify it
  3: the report nails this root cause --- it correctly identifies the cause, its
     mechanism, and the supporting signals

Scoring is based on content correctness only; do NOT reward or penalize formatting,
prose style, or structure. Missing detail or an incomplete explanation is NOT a
materially wrong claim.

Report ``score`` as the raw 0-3 rubric match WITHOUT applying any penalty --- the
penalty is applied downstream, so do NOT lower ``score`` yourself.

Materially-wrong-claim flag: if the report ALSO makes a materially wrong or misleading
claim (e.g. invents an unrelated additional cause, or asserts a mechanism contradicted by
the confirmed cause), set materially_wrong_claim=true and paraphrase the offending
claim in offending_claim (this later costs the report one point). Naming several plausible
candidate causes is NOT by itself a materially wrong claim. Do not set
materially_wrong_claim=true without naming the offending claim.

First decide ground_truth_verdict from the confirmed root cause text:
  verified_cause: it states a specific verified cause.
  contradicted: it states no verified cause, but its evidence refutes the cause the
    report gave as the root cause (for example, the deployment the report blamed never
    reached the affected service, or the blamed signal stayed flat while the alert cleared).
  unresolved: it states no verified cause and does not refute the report's cause, for
    example because the cause is unknown or the report named no cause.
When it is unresolved, answer every other field with false, 0 or an empty string.
When it is contradicted, there is no confirmed cause to match, so answer root_cause_match,
mechanism_match and evidence_match false. Score 0 when the report asserted the refuted
cause as the root cause, and set materially_wrong_claim=true with that claim as
offending_claim. Score 1 when the report named the refuted cause only as one of several
candidates, or only restated the symptoms; that is not a materially wrong claim.

Write every reasoning field as one short sentence in your own words. Summarise what you found; do not quote log lines, query results, or messages from the investigation.
