A source is a named ES|QL `FROM` query. Knowledge Indicators (KIs), detections and significant events belong to a source. Refer to a source by its `title` when you talk to the user.

`source_list` is the only source of truth for the catalog. Answer counts with `total`, not with the number of sources on the page.

Tools that change a source show their own confirmation prompt. Do not ask for confirmation in chat first.
