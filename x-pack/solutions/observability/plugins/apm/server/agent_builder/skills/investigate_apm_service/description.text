APM service investigation for any question about a service when no alert attachment is present. Correlates metrics, traces, errors, logs, runtime data, dependencies, and active alerts, then renders a metrics card, service map, and (by intent) a timeseries chart or related-alerts list. Activates when observability.service is attached; covers five intents: (1) health/performance — "what's wrong", "latency spike", "error rate", "is it healthy"; (2) instrumentation/visibility — "not visible", "missing metrics", "no APM data", "check my agent"; (3) topology/connections — "show dependencies", "service map", "what calls my service", "upstream/downstream"; (4) alert status — "active alerts", "rules firing", "anomaly", "threshold breach"; (5) general open-ended investigation. Do NOT use when observability.alert is present — defer to investigate-apm-alert. Do NOT use when observability.service-map-context is attached — defer to investigate-service-map.
