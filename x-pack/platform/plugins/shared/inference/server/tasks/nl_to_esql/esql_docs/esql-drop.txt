# DROP

The `DROP` processing command removes one or more columns.

## Syntax

`DROP columns`

### Parameters

#### columns

A comma-separated list of columns to remove. Supports wildcards.

## Examples

Remove the `height` column from the `employees` rows.

```esql
FROM employees
| DROP height
```

Remove all columns with names matching the `height*` wildcard pattern.

```esql
FROM employees
| DROP height*
```

## Limitations

A wildcard pattern that matches no columns causes the query to fail with an error such as `No matches found for pattern [columns*]`.

The exception is when `SET unmapped_fields` is set to `"nullify"` or `"load"`: in that case, a pattern that matches no columns is ignored.
