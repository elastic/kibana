# FROM

The `FROM` source command returns a table with data from an index, data stream, alias, view, or subquery. Each row in the resulting table represents a document, and each column corresponds to a field.

## Syntax

`FROM index_pattern [METADATA fields]`

`FROM index_pattern [, (FROM index_pattern [METADATA fields] [| processing_commands])]* [METADATA fields]`

`FROM (FROM index_pattern [METADATA fields] [| processing_commands]) [, (FROM index_pattern [METADATA fields] [| processing_commands])]* [METADATA fields]`

### Parameters

#### `index_pattern`

A list of indices, data streams, aliases, or views. Supports wildcards and date math.

#### `fields`

Optional.

A comma-separated list of metadata fields to retrieve.

## Examples

Query the `employees` index:

```esql
FROM employees
```

Use date math to query today’s `logs` index:

```esql
FROM <logs-{now/d}>
```

Query multiple indices with a comma-separated list and a wildcard:

```esql
FROM employees-00001,other-employees-*
```

Query indices on remote clusters with `<remote_cluster_name>:<target>`:

```esql
FROM cluster_one:employees-00001,cluster_two:other-employees-*
```

Query across the origin serverless project and linked projects by default.

Include the `_id` metadata field with the `METADATA` directive:

```esql
FROM employees METADATA _id
```

Escape index names that contain special characters with double quotes or triple double quotes:

```esql
FROM "this=that", """this[that"""
```

Combine a regular index pattern with a `FROM` subquery:

```esql
FROM
    employees,
    (FROM sample_data | WHERE client_ip == "172.21.3.15")
```

## Limitations

For time series data, use the `TS` source command instead of `FROM`. `TS` enables time series aggregation functions and is optimized for processing time series indices.

A query without an explicit `LIMIT` uses an implicit limit of 1000. For example:

Retrieve documents from the `employees` index without specifying an explicit row limit:

```esql
FROM employees
```

is executed as:

Retrieve documents from the `employees` index with the implicit default limit applied:

```esql
FROM employees
| LIMIT 1000
```
