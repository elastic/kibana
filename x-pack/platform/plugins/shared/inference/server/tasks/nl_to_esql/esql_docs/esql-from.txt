# FROM

The `FROM` source command returns a table with data from an index, data stream, alias, view, or subquery. Each row represents a document, and each column corresponds to a field.

For time series data, use the `TS` source command instead of `FROM`. `TS` enables time series aggregation functions and is optimized for processing time series indices.

## Syntax

`FROM index_pattern [METADATA fields]`

`FROM index_pattern [, (FROM index_pattern [METADATA fields] [| processing_commands])]* [METADATA fields]`

`FROM (FROM index_pattern [METADATA fields] [| processing_commands]) [, (FROM index_pattern [METADATA fields] [| processing_commands])]* [METADATA fields]`

### Parameters

#### `index_pattern`

A list of indices, data streams, aliases, or views. Supports wildcards and date math.

#### `fields`

Optional.

A comma-separated list of metadata fields to retrieve.

## Examples

Query the `employees` index:

```esql
FROM employees
```

Use date math to access today’s `logs` index:

```esql
FROM <logs-{now/d}>
```

Query multiple indices with comma-separated targets and wildcards:

```esql
FROM employees-00001,other-employees-*
```

Query data streams and indices on remote clusters:

```esql
FROM cluster_one:employees-00001,cluster_two:other-employees-*
```

By default, queries run across the origin serverless project and all linked projects.

Include the `_id` metadata field:

```esql
FROM employees METADATA _id
```

Escape index names that contain special characters with double quotes or triple double quotes:

```esql
FROM "this=that", """this[that"""
```

Combine an index target with a `FROM` subquery:

```esql
FROM
    employees,
    (FROM sample_data | WHERE client_ip == "172.21.3.15")
```

## Limitations

A query without an explicit `LIMIT` uses an implicit limit of 1000 rows. A `FROM` command without `LIMIT`:

```esql
FROM employees
```

is executed as:

```esql
FROM employees
| LIMIT 1000
```
