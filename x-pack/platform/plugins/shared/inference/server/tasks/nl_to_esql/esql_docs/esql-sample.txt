# SAMPLE

The `SAMPLE` command samples a fraction of the table rows.

For automatic sampling with extrapolation and confidence intervals, see Approximate `STATS` queries.

## Syntax

`SAMPLE probability`

### Parameters

#### probability

The probability that a row is included in the sample. The value must be between 0 and 1, exclusive.

## Examples

Sample 5% of employee rows and keep only employee numbers.

```esql
FROM employees
| KEEP emp_no
| SAMPLE 0.05
```
