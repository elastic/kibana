# WHERE

The `WHERE` processing command produces a table containing only the rows from the input table for which the provided condition evaluates to `true`.

For value exclusions, fields with `null` values are excluded from search results. In this context, `null` means either an explicit `null` value in the document or no value at all. For example, `WHERE field != "value"` is interpreted as `WHERE field != "value" AND field IS NOT NULL`.

## Syntax

`WHERE expression`

### Parameters

#### expression

A boolean expression.

## Examples

Filter employees by the `still_hired` boolean field.

```esql
FROM employees
| KEEP first_name, last_name, still_hired
| WHERE still_hired == true
```

Filter employees by the `still_hired` boolean field using shorthand boolean syntax.

```esql
FROM employees
| KEEP first_name, last_name, still_hired
| WHERE still_hired
```

Retrieve logs from the last hour using date math.

```esql
FROM sample_data
| WHERE @timestamp > NOW() - 1 hour
```

Filter employees by applying the `LENGTH` function to `first_name`.

```esql
FROM employees
| KEEP first_name, last_name, height
| WHERE LENGTH(first_name) < 4
```

Find employees with a `null` `birth_date`.

```esql
FROM employees
| WHERE birth_date IS NULL
```

first_name:keyword | last_name:keyword
Basil | Tramer
Florian | Syrotiuk
Lucien | Rosenbaum

Count employees with a non-null `is_rehired` value.

```esql
FROM employees
| WHERE is_rehired IS NOT NULL
| STATS COUNT(emp_no)
```

COUNT(emp_no):long
84

Match books where the `author` field contains `Faulkner`.

```esql
FROM books
| WHERE MATCH(author, "Faulkner")
```

book_no:keyword | author:text
2378 | [Carol Faulkner, Holly Byers Ochoa, Lucretia Mott]
2713 | William Faulkner
2847 | Colleen Faulkner
2883 | William Faulkner
3293 | Danny Faulkner

Match books where the `title` field contains all specified terms.

```esql
FROM books
| WHERE MATCH(title, "Hobbit Back Again", {"operator": "AND"})
| KEEP title;
```

title:text
The Hobbit or There and Back Again

Filter employees by `first_name` using a `LIKE` wildcard pattern.

```esql
FROM employees
| WHERE first_name LIKE """?b*"""
| KEEP first_name, last_name
```

first_name:keyword | last_name:keyword
Ebbe | Callaway
Eberhardt | Terkki

Match a literal `*` character in a string with `LIKE`.

```esql
ROW message = "foo * bar"
| WHERE message LIKE "foo \\* bar"
```

Match a literal `*` character with `LIKE` using triple-quoted strings.

```esql
ROW message = "foo * bar"
| WHERE message LIKE """foo \* bar"""
```

Match a Windows-style path using `LIKE`.

```esql
ROW path = """C:\Windows\System32\foo.txt"""
| WHERE path LIKE """C:\\Windows*"""
```

Filter a string against multiple `LIKE` patterns.

```esql
ROW message = "foobar"
| WHERE message like ("foo*", "bar?")
```

Filter employees using a `LIKE` pattern provided by a REST query placeholder.

```esql
FROM employees
| WHERE first_name LIKE ?pattern
| KEEP first_name, last_name
```

Filter employees using a `LIKE` pattern built with `CONCAT`.

```esql
from employees | where first_name like concat("Eber", "*") | keep emp_no, first_name
```

Filter employees by `first_name` using an `RLIKE` regular expression.

```esql
FROM employees
| WHERE first_name RLIKE """.leja.*"""
| KEEP first_name, last_name
```

first_name:keyword | last_name:keyword
Alejandro | McAlpine

Match a literal `(` character in a string with `RLIKE`.

```esql
ROW message = "foo ( bar"
| WHERE message RLIKE "foo \\( bar"
```

Match a literal `(` character with `RLIKE` using triple-quoted strings.

```esql
ROW message = "foo ( bar"
| WHERE message RLIKE """foo \( bar"""
```

Filter a string against multiple `RLIKE` patterns.

```esql
ROW message = "foobar"
| WHERE message RLIKE ("foo.*", "bar.")
```

Filter employees using an `RLIKE` pattern provided by a REST query placeholder.

```esql
FROM employees
| WHERE first_name RLIKE ?pattern
| KEEP first_name, last_name
```

Filter employees using an `RLIKE` pattern built with `CONCAT`.

```esql
from employees | where first_name rlike concat("Eber", ".*") | keep emp_no, first_name
```

Test whether an expression equals an element in a list using `IN`.

```esql
ROW a = 1, b = 4, c = 3
| WHERE c-a IN (3, b / 2, a)
```

a:integer | b:integer | c:integer
1 | 4 | 3
