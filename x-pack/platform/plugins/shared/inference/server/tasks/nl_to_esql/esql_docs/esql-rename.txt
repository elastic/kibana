# RENAME

The `RENAME` processing command renames one or more columns. If a column with the new name already exists, it is replaced by the renamed column.

## Syntax

`RENAME old_name1 AS new_name1[, ..., old_nameN AS new_nameN]`

The following syntax is also supported Elastic Stack: Generally available since 9.1:

`RENAME new_name1 = old_name1[, ..., new_nameN = old_nameN]`

Both syntax options can be used interchangeably, but using one consistently improves readability.

### Parameters

#### `old_nameX`

The name of a column you want to rename.

#### `new_nameX`

The new name of the column. If it conflicts with an existing column name, the existing column is dropped. If multiple columns are renamed to the same name, all but the rightmost column with the same new name are dropped.

## Examples

Rename the `still_hired` column to `employed` while keeping only the employee name and hiring status columns:

```esql
FROM employees
| KEEP first_name, last_name, still_hired
| RENAME  still_hired AS employed
```

Rename `first_name` to `fn` and `last_name` to `ln` in one command:

```esql
FROM employees
| KEEP first_name, last_name
| RENAME first_name AS fn, last_name AS ln
```

Rename `first_name` and `last_name` with sequential `RENAME` commands:

```esql
FROM employees
| KEEP first_name, last_name
| RENAME first_name AS fn
| RENAME last_name AS ln
```
