# PROCESSING-COMMANDS

- `CHANGE_POINT` Elastic Stack: Preview since 9.1 Elastic Stack: Generally available since 9.2
- `COMPLETION` Elastic Stack: Preview since 9.1 Elastic Stack: Generally available since 9.3
