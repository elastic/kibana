# BINARY OPERATORS

Binary operators compare values, perform arithmetic, and return a result based on the operator and operand types.

## Syntax

`BINARY OPERATORS()`

### Parameters

#### lhs

The left-hand side value or field used by the operator.

#### rhs

The right-hand side value or field used by the operator.

#### operator

The binary operator applied to `lhs` and `rhs`.

Supported operators include:

- Equality
- Inequality `!=`
- Less than `<`
- Less than or equal to `<=`
- Greater than `>`
- Greater than or equal to `>=`
- Add `+`
- Subtract `-`
- Multiply `*`
- Divide `/`
- Modulus `%`

## Limitations

If either operand is multivalued, the result is `null`.

Equality, inequality, and comparison operators are pushed to the underlying search index only when one side of the comparison is constant and the other side is a field in the index that has both a mapping index and doc values.

Division of two integer types yields an integer result, rounding toward `0`. For floating-point division, cast one argument to `DOUBLE`.

For dense vector division, both arguments should be dense vectors. Dense vectors with unequal dimensions return `null`.
