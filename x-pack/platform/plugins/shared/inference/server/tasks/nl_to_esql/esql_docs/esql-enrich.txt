# ENRICH

The ENRICH command adds data from existing indices as new columns using an enrich policy.

Before you can use `ENRICH`, you need to create and execute an enrich policy. In case of name collisions, newly created columns override existing columns.

Consider using `LOOKUP JOIN` instead of `ENRICH` for your use case.

## Syntax

`ENRICH policy [ON match_field] [WITH [new_name1 = ]field1, [new_name2 = ]field2, ...]`

### Parameters

#### policy

The name of the enrich policy. You need to create and execute the enrich policy first.

#### mode

The mode of the enrich command in cross-cluster queries.

#### match_field

Optional.

The match field. `ENRICH` uses its value to look for records in the enrich index. If not specified, the match is performed on the column with the same name as the `match_field` defined in the enrich policy.

#### fieldX

Optional.

The enrich fields from the enrich index that are added to the result as new columns. If a column with the same name as the enrich field already exists, the existing column is replaced by the new column. If not specified, each of the enrich fields defined in the policy is added. A column with the same name as the enrich field is dropped unless the enrich field is renamed.

#### new_nameX

Optional.

Changes the name of the column added for each enrich field. Defaults to the enrich field name. If a column has the same name as the new name, it is discarded. If a name, new or original, occurs more than once, only the rightmost duplicate creates a new column.

## Examples

Use the default policy match field to enrich a `language_code` value:

```esql
ROW language_code = "1"
| ENRICH languages_policy
```

language_code:keyword | language_name:keyword
1 | English

Match records using a different input column with `ON`:

```esql
ROW a = "1"
| ENRICH languages_policy ON a
```

a:keyword | language_name:keyword
1 | English

Select a specific enrich field with `WITH`:

```esql
ROW a = "1"
| ENRICH languages_policy ON a WITH language_name
```

a:keyword | language_name:keyword
1 | English

Rename an enrich field with `WITH new_name = field`:

```esql
ROW a = "1"
| ENRICH languages_policy ON a WITH name = language_name
```

a:keyword | name:keyword
1 | English
