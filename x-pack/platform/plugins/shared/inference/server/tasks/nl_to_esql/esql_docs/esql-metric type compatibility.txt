# METRIC TYPE COMPATIBILITY

Metric type compatibility determines which time series aggregation functions can be used with a field based on the field's `metric_type` mapping.

The inner function you pick depends on the field's `metric_type` mapping:

- **Counters**: monotonically increasing values that reset on process restart. Use `RATE`, `INCREASE`, and the other counter-aware functions. These detect resets per time series and compute correct deltas; applying a gauge-only function such as `AVG_OVER_TIME` to a counter is rarely what you want.
- **Gauges**: point-in-time values that can move up or down. Use `LAST_OVER_TIME`, the implicit default for numeric fields when no inner function is given, `AVG_OVER_TIME`, `MAX_OVER_TIME`, and the other `*_OVER_TIME` variants. Counter functions like `RATE` reject gauge fields.
- **Histograms** Elastic Stack: Generally available since 9.4, Elastic Stack: Preview in 9.3: distributions stored as `exponential_histogram`, `tdigest`, or `histogram` fields. You usually don't need a time series aggregation function: apply a regular aggregation such as `SUM`, `AVG`, or `PERCENTILE` directly to the field, and `TS` implicitly merges the histograms per time series. Fields with the type `histogram` must first be cast using `::exponential_histogram` or `::tdigest`.
- **Any metric type** Elastic Stack: Planned: `COUNT_OVER_TIME`, `PRESENT_OVER_TIME`, and `ABSENT_OVER_TIME` only look at whether samples exist, not at their values, so they accept counters as well as gauges.

The following time series aggregation functions are supported:

- `ABSENT_OVER_TIME` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the absence of a field over a time range.
- `AVG_OVER_TIME` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the average over time of a numeric field.
- `CHANGES` Elastic Stack: Planned: Calculates the number of value changes in a time window.
- `COUNT_OVER_TIME` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the count over time value of a field.
- `COUNT_DISTINCT_OVER_TIME` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the count of distinct values over time for a field.
- `DELTA` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the absolute change of a gauge field in a time window.
- `DERIV` Elastic Stack: Preview since 9.3: Calculates the derivative over time of a numeric field using linear regression.
- `FIRST_OVER_TIME` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the earliest value of a field over a time window.
- `IDELTA` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the absolute change between the last two data points of a gauge.
- `INCREASE` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the absolute increase of a counter field in a time window.
- `IRATE` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the per-second rate of increase between the last two data points.
- `LAST_OVER_TIME` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the latest value of a field over a time window.
- `MAX_OVER_TIME` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the maximum value of a field over a time window.
- `MIN_OVER_TIME` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the minimum value of a field over a time window.
- `PERCENTILE_OVER_TIME` Elastic Stack: Preview since 9.3: Calculates the percentile over time of a field.
- `PRESENT_OVER_TIME` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the presence of a field over a time range.
- `RATE` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the per-second average rate of increase of a counter.
- `STDDEV_OVER_TIME` Elastic Stack: Preview since 9.3: Calculates the population standard deviation over time of a numeric field.
- `SUM_OVER_TIME` Elastic Stack: Preview since 9.2 Elastic Stack: Generally available since 9.4: Calculates the sum over time value of a field.
- `VARIANCE_OVER_TIME` Elastic Stack: Preview since 9.3: Calculates the population variance over time of a numeric field.

## Limitations

Counter functions like `RATE` reject gauge fields. Gauge-only functions such as `AVG_OVER_TIME` are rarely appropriate for counters. Fields with the type `histogram` must first be cast using `::exponential_histogram` or `::tdigest`.
