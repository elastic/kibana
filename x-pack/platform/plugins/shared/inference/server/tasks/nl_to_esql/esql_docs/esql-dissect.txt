# DISSECT

The DISSECT command extracts structured data from a string. It matches the string against a delimiter-based pattern and extracts the specified keys as columns.

## Syntax

`DISSECT input "pattern" [APPEND_SEPARATOR="<separator>"]`

### Parameters

#### input

The column that contains the string you want to structure. If the column has multiple values, DISSECT will process each value.

#### pattern

A dissect pattern. If a field name conflicts with an existing column, the existing column is dropped. If a field name is used more than once, only the rightmost duplicate creates a column.

#### <separator>

Optional. A string used as the separator between appended values, when using the append modifier.

## Examples

Parse a string that contains a timestamp, text, and an IP address into separate columns:

```esql
ROW a = "2023-01-23T12:15:00.000Z - some text - 127.0.0.1"
| DISSECT a """%{date} - %{msg} - %{ip}"""
| KEEP date, msg, ip
```

Extract fields from a string and convert the parsed timestamp from a keyword value to a date column:

```esql
ROW a = "2023-01-23T12:15:00.000Z - some text - 127.0.0.1"
| DISSECT a """%{date} - %{msg} - %{ip}"""
| KEEP date, msg, ip
| EVAL date = TO_DATETIME(date)
```
