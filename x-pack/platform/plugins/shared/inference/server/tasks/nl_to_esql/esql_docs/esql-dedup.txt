# DEDUP

`DEDUP` removes duplicate rows from a result set, keeping one row per unique combination of values across all columns. It compares all columns currently in scope and discards exact duplicate rows. Null values are treated as equal for deduplication.

`DEDUP` is equivalent to `LIMIT 1 BY <all columns>`. Use `LIMIT ... BY` directly to keep more than one row per unique combination, or to deduplicate using only a subset of columns.

## Syntax

`DEDUP`

### Parameters

`DEDUP` takes no arguments.

## Examples

Remove duplicate values from a single column:

```esql
FROM employees
| WHERE emp_no IN (10001, 10002, 10003, 10005, 10006)
| KEEP gender
| DEDUP
| SORT gender
```

gender:keyword  
F  
M

Remove rows that are duplicates across multiple columns:

```esql
FROM employees
| WHERE emp_no IN (10001, 10002, 10010, 10011)
| KEEP gender, languages
| DEDUP
| SORT gender NULLS LAST, languages
```

gender:keyword | languages:integer  
F | 5  
M | 2  
null | 4  
null | 5

Keep up to two rows per unique `languages` value with `LIMIT ... BY`:

```esql
FROM employees
| WHERE emp_no IN (10001, 10003, 10007, 10008, 10010)
| KEEP languages
| LIMIT 2 BY languages
| SORT languages
```

languages:integer  
2  
2  
4  
4

Deduplicate by `gender` while keeping selected employee columns:

```esql
FROM employees
| WHERE emp_no IN (10001, 10002, 10003, 10005, 10006)
| SORT last_name
| LIMIT 1 BY gender
| KEEP first_name, last_name, gender
```

first_name:keyword | last_name:keyword | gender:keyword  
Parto | Bamford | M  
Anneke | Preusig | F

## Limitations

`DEDUP` cannot be used when any column in scope has one of the following types: `aggregate_metric_double`, counter types (`counter_long`, `counter_integer`, `counter_double`), or `date_range`. Attempting to do so results in a validation error.

Columns of an `unsupported` type are ignored when comparing rows, and `DEDUP` does not fail because of them. This includes fields mapped to incompatible types across the indices of a `FROM` command. Such fields are returned as `null` until converted, so they cannot distinguish rows. Convert these fields before using `DEDUP` if their values should be used for deduplication.

Full-text search functions, such as `MATCH` or `KQL`, cannot appear after `DEDUP` in the same pipeline.
