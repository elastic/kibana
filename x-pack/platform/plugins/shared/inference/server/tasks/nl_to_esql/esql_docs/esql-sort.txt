# SORT

The `SORT` processing command sorts a table on one or more expressions. You can sort by column names, functions, or arithmetic expressions.

## Syntax

`SORT expression1 [ASC/DESC][NULLS FIRST/NULLS LAST][, ..., expressionN [ASC/DESC][NULLS FIRST/NULLS LAST]]`

### Parameters

#### `expressionX`

The expression to sort on. Can be a column name, a function (for example, `length(field)`, `DATE_EXTRACT("year", date)`), or an arithmetic expression (for example, `salary * 2`). The expression is evaluated per row and the result is used for ordering.

#### `ASC/DESC`

Optional. The sort order. The default sort order is ascending. Use `ASC` or `DESC` to specify an explicit sort order.

#### `NULLS FIRST/NULLS LAST`

Optional. The placement of `null` values in the sort order. By default, `null` values are treated as being larger than any other value. With an ascending sort order, `null` values are sorted last, and with a descending sort order, `null` values are sorted first.

## Examples

Sort employee rows by height in default ascending order.

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT height
```

Sort employee rows by height in descending order.

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT height DESC
```

Break height ties with an additional first-name sort expression.

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT height DESC, first_name ASC
```

Place `null` first-name values first in an ascending sort.

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT first_name ASC NULLS FIRST
```

Sort rows by the length of the `first_name` field in descending order.

```esql
FROM employees
| KEEP first_name, last_name
| SORT length(first_name) DESC
| LIMIT 5
```
