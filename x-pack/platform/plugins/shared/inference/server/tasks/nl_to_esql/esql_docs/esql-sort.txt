# SORT

The `SORT` processing command sorts a table on one or more expressions. The default sort order is ascending. Additional sort expressions can act as tie breakers. Sorting on multivalued columns uses the lowest value when sorting ascending and the highest value when sorting descending.

## Syntax

`SORT expression1 [ASC/DESC][NULLS FIRST/NULLS LAST][, ..., expressionN [ASC/DESC][NULLS FIRST/NULLS LAST]]`

### Parameters

#### expressionX

The expression to sort on. Can be a column name, a function, such as `length(field)` or `DATE_EXTRACT("year", date)`, or an arithmetic expression, such as `salary * 2`. The expression is evaluated per row and the result is used for ordering.

#### ASC/DESC

Optional. Specifies the sort order for the expression. Use `ASC` for ascending order or `DESC` for descending order. The default sort order is ascending.

#### NULLS FIRST/NULLS LAST

Optional. Controls where `null` values are placed. By default, `null` values are treated as larger than any other value, so they are sorted last in ascending order and first in descending order.

## Examples

Sort employee heights in default ascending order:

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT height
```

Sort employee heights in descending order:

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT height DESC
```

Sort employee heights in descending order and break ties by first name in ascending order:

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT height DESC, first_name ASC
```

Sort employee first names in ascending order with null values first:

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT first_name ASC NULLS FIRST
```

Sort employees by the length of `first_name` in descending order and return the first five results:

```esql
FROM employees
| KEEP first_name, last_name
| SORT length(first_name) DESC
| LIMIT 5
```
