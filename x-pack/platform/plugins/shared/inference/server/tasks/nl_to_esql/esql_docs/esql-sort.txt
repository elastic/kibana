# SORT

The `SORT` processing command sorts a table on one or more expressions. You can sort by column names, functions, or arithmetic expressions. The default sort order is ascending.

## Syntax

`SORT expression1 [ASC/DESC][NULLS FIRST/NULLS LAST][, ..., expressionN [ASC/DESC][NULLS FIRST/NULLS LAST]]`

### Parameters

#### `expressionX`

The expression to sort on. Can be a column name, a function (for example, `length(field)`, `DATE_EXTRACT("year", date)`), or an arithmetic expression (for example, `salary * 2`). The expression is evaluated per row and the result is used for ordering.

#### `ASC/DESC`

Optional. Specifies the sort order. Use `ASC` for ascending order or `DESC` for descending order. If no sort order is specified, ascending order is used.

#### `NULLS FIRST/NULLS LAST`

Optional. Controls where `null` values are placed. By default, `null` values are treated as larger than any other value: they are sorted last in ascending order and first in descending order.

## Examples

Sort employees by height in default ascending order.

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT height
```

Sort employees by height in descending order with `DESC`.

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT height DESC
```

Break height ties by sorting employees with the same height by first name in ascending order.

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT height DESC, first_name ASC
```

Place `null` first names first while sorting names in ascending order.

```esql
FROM employees
| KEEP first_name, last_name, height
| SORT first_name ASC NULLS FIRST
```

Sort employees by the length of `first_name` in descending order and return the first five results.

```esql
FROM employees
| KEEP first_name, last_name
| SORT length(first_name) DESC
| LIMIT 5
```
