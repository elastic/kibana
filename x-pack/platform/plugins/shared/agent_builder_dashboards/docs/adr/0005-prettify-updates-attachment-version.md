# Prettify updates the conversation dashboard in place

The Prettify result is a new version of the same dashboard attachment already in the conversation, not a second attachment and not an immediate saved-object write. Reject means do not persist to the Kibana saved object. Save over / save as copy reuse the existing origin/save UI.

The GitHub issue’s “new attachment” language is satisfied by a new version the user can preview in chat, not by forking a second dashboard id.
