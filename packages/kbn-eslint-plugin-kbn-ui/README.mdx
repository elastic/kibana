`@kbn/eslint-plugin-kbn-ui` is a collection of custom ESLint rules for `@kbn/ui-` components.

## `@kbn/kbn-ui/no_restricted_package_imports`

Bans importing listed kbn-ui platform implementation packages outside allowlisted paths, and shows each package's `alternative` (the contract to use instead). Enabled as an error in the shared ESLint config.

Policy: `src/platform/kbn-ui/_tooling/eslint_boundaries.js`. List a package under `packages` to restrict it; add `overrides` for owners that must import it. Do not put path exceptions in the root ESLint config.

### Examples

```ts
// valid — allowlisted owner
import type { FeedbackRegistryEntry } from '@kbn/ui-feedback';

// invalid — app plugin
import { Feedback } from '@kbn/ui-feedback';
import { ChromeLayout } from '@kbn/ui-chrome-layout';
```

## `@kbn/kbn-ui/prefer_kbn_ui_callout`

Flags direct usage of `<EuiCallOut>` in favour of the semantic wrapper components from `@kbn/ui-callout`.

Choose the wrapper that matches the intent:

| `EuiCallOut` color  | Wrapper             |
| ------------------- | ------------------- |
| `primary` (default) | `KbnInfoCallout`    |
| `success`           | `KbnSuccessCallout` |
| `warning`           | `KbnWarningCallout` |
| `danger`            | `KbnDangerCallout`  |

**Known limitation:** the rule only detects `<EuiCallOut>` in JSX. Usage as a value (e.g. `const C = condition ? EuiCallOut : Other`) is not flagged.

### Examples

✅ valid

```tsx
import { KbnWarningCallout } from '@kbn/ui-callout';

<KbnWarningCallout title="Something went wrong" />;
```

❌ invalid

```tsx
import { EuiCallOut } from '@elastic/eui';

// No color — EuiCallOut defaults to primary (info)
<EuiCallOut title="Note" />

// Known color
<EuiCallOut color="warning" title="Something went wrong" />

// Spread props
<EuiCallOut {...props} title="Note" />
```

## `@kbn/kbn-ui/prefer_toast_action_props`

Flags legacy usage of passing actions as content to toasts that are added via the `ToastsApi`'s methods (`add()`, `addInfo()`, `addSuccess()`, `addWarning()`, `addDanger()`) as actions should instead be passed via the `actionProps` prop.

### Examples

✅ valid

```tsx
// Action passed via actionProps
toasts.addSuccess({
  title: 'Done',
  actionProps: { primary: { label: 'Action', onClick: () => {} } },
});

// Inline hyperlink as part of translated sentence — not a standalone CTA
toasts.addSuccess({
  title: 'Done',
  text: toMountPoint(
    <FormattedMessage
      id="x"
      defaultMessage="See {docs} for details."
      values={{ docs: <EuiLink href="/">Link</EuiLink> }}
    />
  ),
});
toasts.addSuccess({
  title: 'Done',
  text: toMountPoint(
    <>
      <FormattedMessage id="x" defaultMessage="See the docs for details:" />
      <EuiLink href="/">Link</EuiLink>
    </>
  ),
});

// custom component wrapper (valid, but unexpected)
toasts.addSuccess({
  title: 'Done',
  text: mountReactNode(
    <CustomComponent>
      <EuiButton>Action</EuiButton>
    </CustomComponent>
  ),
});
```

❌ invalid

```tsx
// Action button embedded in mounted JSX text
toasts.addSuccess({
  title: 'Done',
  text: toMountPoint(
    <EuiFlexGroup justifyContent="flexEnd">
      <EuiFlexItem grow={false}>...</EuiFlexItem>
      <EuiFlexItem grow={false}>
        <EuiButton>Action</EuiButton>
      </EuiFlexItem>
    </EuiFlexGroup>,
    services
  ),
});

// Standalone button CTA
toasts.addWarning({
  title: 'Warning',
  text: mountReactNode(
    <div>
      <p>Additional configuration is required before you can proceed.</p>
      <EuiButton>Action</EuiButton>
    </div>
  ),
});

// Standalone link CTA after body text
toasts.addWarning({
  title: 'Warning',
  text: mountReactNode(
    <div>
      <p>Additional configuration is required before you can proceed.</p>
      <EuiLink href="/">Link</EuiLink>
    </div>
  ),
});
```
